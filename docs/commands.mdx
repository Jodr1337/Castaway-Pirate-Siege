# Commands Reference

Operator and server administrator commands for **Castaway: Pirate Siege**.

---

## 💻 In-Game Commands

| Command | Permission | Description |
| :--- | :---: | :--- |
| `/castaway raid start` | OP | Initiates the pirate siege warning phase and begins wave timers. |
| `/castaway raid assault` | OP | Immediately skips to the active naval assault wave. |
| `/castaway raid stop` | OP | Instantly halts and resets any active pirate raid. |
| `/castaway flotsam [count]` | OP | Spawns `count` drifting cargo crates offshore (Default: 3). |
| `/castaway smuggler` | OP | Summons the Wandering Smuggler on a trading raft. |
| `/castaway ghostship spawn` | OP | Automatically scans and spawns the Spectral Ghost Galleon. |
| `/castaway ghostship despawn` | OP | Dismisses the ghost ship, removes entities, and restores ocean water. |
